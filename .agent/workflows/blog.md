---
description: How to add a new blog post to the portfolio
---

1. Create a new HTML file in `/home/lek/Desktop/PORTFILO/blog/posts/` with the name format `YYYY-MM-DD-slug.html`.
2. Use the standard blog template (you can copy it from `2026-06-21-mastering-the-command-line.html`).
// turbo
3. Add the post metadata (slug, title, excerpt, date) to `/home/lek/Desktop/PORTFILO/blog/posts.json`.
4. Refresh the site on `http://localhost:3000/blog.html` to see the changes.
